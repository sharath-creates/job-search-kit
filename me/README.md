# me/

Your answers live here. Everything in this folder except this file and
`EXAMPLE-profile.md` is gitignored, so your salary floor and your email
address never reach GitHub.

Setup writes four files here:

| File | What it holds |
|---|---|
| `profile.md` | Who you are, what you want, what you will not accept |
| `answer-sheet.md` | Your stock answers to application form fields |
| `guardrails.md` | The rules every scheduled task obeys before it acts |
| `setup-state.md` | Which setup steps are done, and the IDs of your tasks |

If you want to start over, delete these four files and say "run setup".
